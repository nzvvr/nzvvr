# Rediseño orbital del perfil

**Fecha:** 2026-07-10  
**Dirección:** Órbita editorial

## Objetivo

Transformar el README en una experiencia visual continua inspirada en una landing page espacial. Un único SVG vertical reunirá identidad, experiencia, especialidades, stack y filosofía; los enlaces de contacto permanecerán como HTML debajo para conservar su interacción en GitHub.

## Composición

- **Escena superior:** planeta rojizo y violeta, horizonte atmosférico, estrellas y una nave geométrica.
- **Hero:** Javier Sepúlveda, `nzvvr`, Software Engineer y AI Engineer.
- **Experiencia:** más de cuatro años en software, más de dos años en IA y rol actual en Microsystem.
- **Especialidades:** productos con IA, plataformas modernas, experiencias digitales y cloud.
- **Stack:** Frontend, Backend, IA y Cloud como constelaciones visuales.
- **Cierre:** principio profesional sobre la relación entre ingeniería y diseño.
- **Contacto externo:** LinkedIn, correo y futura web debajo del SVG.

## Lenguaje visual

Fondo azul-negro, planeta cálido, acentos violeta, rosa, cian y blanco. La profundidad se construirá con gradientes, máscaras, filtros, partículas y líneas orbitales. Los paneles usarán superficies translúcidas y bordes sutiles.

## Restricciones

- Sin imágenes rasterizadas, fuentes remotas ni servicios externos.
- SVG con `viewBox` adaptable y texto alternativo.
- Contenido legible al ancho habitual de un README de GitHub.
- Enlaces reales fuera del SVG, ya que un SVG cargado como imagen no conserva enlaces internos interactivos.

## Verificación

- Renderizar el SVG a resolución completa y reducida.
- Revisar contraste, jerarquía, desbordes y legibilidad.
- Validar el SVG mediante un render real.
- Comprobar enlaces, formato Markdown y estado de Git antes de publicar.
